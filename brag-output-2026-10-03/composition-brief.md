# Composition Brief: NinjaOne Infra Dashboard (Cinematic Datacenter)

## Resolution & Duration
- Resolution: 1920x1080 (Landscape, 16:9)
- Framerate: 30 fps
- Total Frames: 900 (30.0 seconds)

## Tone & Visual Style
- Tone: `cinematic` IT hardware datacenter
- Style: Obsidian datacenter floor (`#030712`), perspective server rack units with animated blinking LEDs, illuminated fiber-optic data bus lines with glowing pulse particles flowing from server to server.
- High-contrast HUD elements with neon cyan (`#00e5ff`), emerald (`#00e676`), and amber (`#ffb300`).

## Audio Structure
- Background Music: `assets/music/happy-beats-business-moves-vol-11-by-ende-dot-app.mp3`
- SFX tracks placed on distinct indices (11 to 16)
- Transitions aligned to scene boundaries (7.5s, 15.0s, 22.5s, 30.0s).

## Key Scenes & Flow
1. Scene 1 (0.0s - 7.5s): Datacenter Server Racks & Flowing Data Lines + 1,704 Node Scope.
2. Scene 2 (7.5s - 15.0s): Dual-Engine Patch Slicer & Live Compliance Speedometer Gauge.
3. Scene 3 (15.0s - 22.5s): Multi-Cloud Server Topology Mesh (AWS, Azure, GCP, On-Prem) & Real-time Audit Ledger.
4. Scene 4 (22.5s - 30.0s): Executive Climax, Multi-Format Audit Badges, Standalone Portability.
